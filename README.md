🎓 Student Success Saga — 2D Idle Game (Unity, C#)
Student Success Saga is a 2D idle/clicker game about the daily life of a university student — managing time, studying, working part-time, exercising, and taking breaks in order to stay balanced and graduate successfully.
The game is developed with Unity and programmed in C#, designed to practice game economy systems, progression, UI design, and a simple save/load system.

Status: In Development

✨ Features
- Idle system that generates resources over time, even when the player is not actively interacting
- Various activities: studying, reading, part-time jobs, attending events
- Skill and stat system (e.g., Knowledge, Happiness, Money)
- Level-up and unlock system for new activities and items
- Save / Load system (using PlayerPrefs or JSON files)
- UI/UX for main screens, menus, and event pop-ups
- Supports build for Windows (PC) (in the full project)
⚠️ Note: This repository contains C# scripts only — assets, scenes, and builds are not included.

🛠 Tools & Technologies
- Unity Engine (development platform)
- C# (main scripting language)
- Unity version control (version control)
- JSON / PlayerPrefs for save system
